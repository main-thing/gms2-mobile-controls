# Mobile controls for GMS2
Custom mobile controls for your GameMaker Studio 2 Projects

# Using this in your project
1. Download latest [release](https://github.com/main-thing/gms2-mobile-controls/releases/tag/v1.0b).
2. Tools > Import Local Package.
3. Add all resources to project.
4. In the starting room of the project (🏠) add the obj_virtual_controller_manager object into your instance layer.
<img width="1666" height="723" alt="image" src="https://github.com/user-attachments/assets/d022190f-bb34-4ec6-b88e-6e47054c79ca" />
5. Create a new assets layer called Buttons_1, and add the buttons you need from the sprites/mobilecontrols folder. (If you need to add more default buttons edit scr_create_default_button)
<img width="1371" height="774" alt="image" src="https://github.com/user-attachments/assets/ca6f5a20-df00-4525-85ae-c3cc36503054" />
6. Run the game and everything should work as expected!
